# AI balíčky

Materiály pro práci s AI v práci: jak nepsat všechno do jednoho nekonečného chatu, kde má práce „bydlet“ a jak vést delší projekt, aby se neztratil směr. Pro začátečníky i pokročilé začátečníky. Stahování nevyžaduje GitHub účet.

## Stáhnout

| Balíček | Co to je | Stáhnout |
|---|---|---|
| **AI Kompas** (RC 0.1) | Pomocník v Claude, který rozhodne, kde má váš pracovní problém bydlet (chat, nebo Project), a připraví hotové nastavení. Instaluje se jednou, za 5 minut. | [AI-Kompas-RC0.1.zip](https://github.com/lurek18/ai-balicky/raw/main/downloads/AI-Kompas-RC0.1.zip) |
| **Projektový start** (v0.3) | Příprava zadání a založení dlouhodobého projektu s AI. Obsahuje šablony souborů (BRIEF, AGENTS, WORKLOG…), vzor a prezentaci. | [Projektovy-start-v0.3.zip](https://github.com/lurek18/ai-balicky/raw/main/downloads/Projektovy-start-v0.3.zip) |
| **Obojí** | oba balíčky v jednom | [AI-balicky-komplet.zip](https://github.com/lurek18/ai-balicky/raw/main/downloads/AI-balicky-komplet.zip) |

**Prezentace (workshop, návod a tahák) online:** https://lurek18.github.io/ai-balicky/ (ovládání šipkami, na 2. slidu je rozcestník)

## Kde začít

1. Rozbalte ZIP a otevřete `START-ZDE.md`.
2. **AI Kompas:** nainstalujte ho na claude.ai (stačí i free účet). Postup je v `START-ZDE.md`.
3. **Projektový start:** když Kompas doporučí Project a práce má fáze a potrvá týdny, pokračujte `01-PRIPRAVA-ZADANI.md`.
