# AI balíčky

Materiály pro práci s AI v práci: jak nepsat všechno do jednoho nekonečného chatu, kde má práce „bydlet“ a jak vést delší projekt, aby se neztratil směr. Pro začátečníky i pokročilé začátečníky.

## Začni tady: https://lurek18.github.io/ai-balicky/

Návod krok za krokem. U každého textu je tlačítko **Kopírovat**, takže nic nestahuješ ani neotvíráš soubory. Stačí účet na claude.ai.

**Prezentace** (workshop, vysvětlení, cvičení): https://lurek18.github.io/ai-balicky/prezentace.html (ovládání šipkami)

## Pro pokročilé: soubory ke stažení

Stahování nevyžaduje GitHub účet. Po stažení ZIP rozbal (Mac: dvojklik, Windows: pravé tlačítko → Extrahovat vše) a otevři `START-ZDE.md`.

| Balíček | Co to je | Stáhnout |
|---|---|---|
| **AI Kompas** (RC 0.1) | Pomocník v Claude, který rozhodne, kde má pracovní problém bydlet (chat, nebo Project), a připraví hotové nastavení. | [AI-Kompas-RC0.1.zip](https://github.com/lurek18/ai-balicky/raw/main/downloads/AI-Kompas-RC0.1.zip) |
| **Projektový start** (v0.3) | Příprava zadání a založení dlouhodobého projektu. Šablony souborů (BRIEF, AGENTS, WORKLOG…), vzor, postupy pro Cowork, Claude Code, Codex a Gemini. | [Projektovy-start-v0.3.zip](https://github.com/lurek18/ai-balicky/raw/main/downloads/Projektovy-start-v0.3.zip) |
| **Obojí** | oba balíčky v jednom | [AI-balicky-komplet.zip](https://github.com/lurek18/ai-balicky/raw/main/downloads/AI-balicky-komplet.zip) |
