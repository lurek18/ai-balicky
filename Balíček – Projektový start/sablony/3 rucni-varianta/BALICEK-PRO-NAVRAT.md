# Balíček pro návrat — obyčejný chat bez instrukcí

> Vlož celý tento blok jako první zprávu každého nového chatu. Obsahuje pravidla, zadání i aktuální stav. Na konci práce napiš „zapiš stav“ a nahraď tu část STAV PROJEKTU novou verzí.

```
BALÍČEK PRO NÁVRAT — [NÁZEV]

== PRAVIDLA ==
[obsah lehké šablony AGENTS]

== ZADÁNÍ ==
[obsah BRIEF]

== STAV PROJEKTU — [NÁZEV] — [DATUM]
Fáze/krok: …
Hotovo naposledy: …
Rozdělané: …
Rozhodnuto (nové): …
Otevřené otázky: …
Nápady na později: …
Další krok: …
```
